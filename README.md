# Anubis

一个“守护秘密的人”：可离线使用的浏览器端加密保险箱，用于保存账号密码、API Token、私密文字和图片。

## 立即运行

```bash
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`。数据仅保存在当前浏览器的 IndexedDB 中。

## 安全设计

- 主密码通过 PBKDF2-SHA-256（310,000 次迭代）派生 256-bit 密钥。
- 内容使用 AES-GCM 加密，且每次加密采用随机 IV。
- 主密码和解密后的密钥不写入磁盘；5 分钟无操作自动锁定。
- 导出文件保持加密，可复制到多个可靠位置，防止设备损坏导致丢失。

## 重要边界

这是可用 MVP，并非经过第三方安全审计的成熟密码管理器。浏览器数据可能被清理，所以务必定期导出备份；主密码无法找回。生产化还需要 CSP、依赖完整性、原生生物识别密钥封装、版本化迁移及独立安全审计。

## 路线图
