# Anubis

一个“守护秘密的人”：可离线、可安装、可多端同步的零知识加密保险箱，用于保存账号密码、API Token、私密文字和图片。

## 立即运行

```bash
node server.js
```

浏览器打开 `http://localhost:8080`。电脑和手机可从浏览器菜单安装成 PWA。除 `localhost` 外，Web Crypto 和 PWA 必须部署在 HTTPS 下。

## 电脑与手机同步

已有保险箱在电脑时：

1. Ubuntu 解锁保险箱，点击“多端同步”显示二维码。
2. 手机点击“扫码加入保险箱”并扫描，随后输入同一个主密码。

已有保险箱在手机、电脑还是空设备时：

1. Ubuntu 点击“从手机接收保险箱”，电脑立即显示临时二维码。
2. 手机点击“扫码加入保险箱”并扫描，确认发送当前加密保险箱。
3. Ubuntu 自动接收密文并显示解锁页。

以后两端修改会自动同步。

同步地址、Vault ID 和随机令牌都包含在二维码中，普通使用不需要手动填写。无相机时仍可展开“手动配对码”作为备用。

服务端默认把加密数据写入 `server-data/`，生产部署应通过 `ANUBIS_DATA_DIR` 指向持久卷：

```bash
ANUBIS_DATA_DIR=/data/anubis PORT=8080 node server.js
```

请为数据目录做异地、版本化备份。服务端保留最近 20 个密文版本；客户端在线时每分钟及每次修改后自动同步。

## Ubuntu 桌面端

```bash
chmod +x ubuntu/install.sh ubuntu/uninstall.sh
./ubuntu/install.sh
```

安装器会创建用户级 systemd 服务和应用菜单入口，不需要 root。卸载入口不会删除 `server-data/` 中的加密数据。

## Android 端

Android 工程位于 `android/`，使用原生 WebView 的 HTTPS 虚拟域名加载随 APK 打包的前端，因此本地加密离线可用。图片选择和加密备份下载已桥接到系统能力。

```bash
./gradlew -p android assembleDebug
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

首次在手机启用同步时，填入可从手机访问的服务器地址（不能填电脑上的 `127.0.0.1`）。公网部署必须使用 HTTPS；局域网调试可临时使用电脑的 LAN IP。

## 安全设计

- 主密码通过 PBKDF2-SHA-256（310,000 次迭代）派生 256-bit 密钥。
- 内容使用 AES-GCM 加密，且每次加密采用随机 IV。
- 主密码和解密后的密钥不写入磁盘；5 分钟无操作自动锁定。
- Android 可在首次主密码解锁后启用系统指纹或锁屏解锁；派生密钥由 Android Keystore 认证密钥封装，主密码不会写入设备偏好设置。
- 导出文件保持加密，可复制到多个可靠位置，防止设备损坏导致丢失。
- 同步身份使用随机 256-bit 令牌；服务器只保存令牌哈希和加密快照。
- 多设备按每条记录的更新时间合并，删除以加密墓碑同步，避免旧设备把已删除内容带回来。

## 重要边界

这是可用 MVP，并非经过第三方安全审计的成熟密码管理器。浏览器数据可能被清理，所以务必定期导出备份；主密码无法找回。配对码可授权下载密文，必须像钥匙一样保护。生产化还需要限流、配额、审计告警及独立安全审计。
